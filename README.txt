# Tsavo Coral Bells BNB Website

Open `index.html` in a browser to preview the website.

## Before publishing
1. Replace `YOUR-EMAIL@example.com` in `index.html` with the booking email.
2. Add a WhatsApp booking number/button if desired.
3. Add photos of the private unit (bedroom, bathroom, kitchen, living area) to `assets/` and place them in the gallery.
4. Add the exact Google Maps location link if desired.

The site is responsive and can be uploaded to Netlify, GitHub Pages, or another static website host.
